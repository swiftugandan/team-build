A crew of agents builds it. The checks decide what lands.

team-build is a Claude Code plugin for large projects. A lead agent turns your spec into milestones with acceptance checks, then runs a crew of helper agents, each in its own git worktree. They coordinate through one SQL board, and a merge queue lands only work that passes.

Install the plugin Read the design

How a run goes

You agree the milestones with the lead. After that, the crew works on its own until every milestone is green.

  1. Scope

    You and the lead agree on milestones. Each one has an acceptance check: a command that passes only when the feature works end to end.

  2. Skeleton

    The lead builds a skeleton on a trunk branch. Every check runs and fails, and each missing piece is a stub that fails loudly.

  3. Staff

    The lead hires helpers into their own worktrees and names a captain for each milestone. Captains post a plan and split the work into tasks.

  4. Run

    Helpers claim tasks, build, test and submit. The merge queue lands one submission at a time. The lead moves helpers to where work is open.

  5. Finish

    With every milestone green, the lead runs the product end to end, gets an independent review, and hands you the trunk branch.

What the merge queue refuses

Trunk moves only after the gate passes, and only by compare-and-swap, so a crash never leaves unchecked code on it. A refused task goes back to the helper who submitted it, with the reason.

Helpers never push and never write trunk. Only the lead can change an acceptance check, and only with your approval.

Where the ideas come from

The design follows Safely scaling multi-agent teams with Claude Fable 5.2, in which a lead and 999 helpers reproduced a Lean proof of Fermat's Last Theorem in 28.7 hours. Lean gave that team a checker. For software, acceptance checks play that part, in the way How the Claude Code team thinks about verification describes.

Install

Add the plugin

/plugin marketplace add swiftugandan/team-build/plugin install team-build@team-build

Run these in Claude Code. You need git, Python 3.9 or later, and macOS or Linux. Every agent runs on the machine that holds the repo.

Start a run

/team-build:team-build docs/prd.md

Open Claude Code in the repo to build and give it your spec. Put a number after the spec to set the crew size; the default is 6. Your checkout stays as it is, and the result arrives on its own branch.
